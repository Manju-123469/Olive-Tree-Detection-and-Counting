
# Olive Tree Detection and Counting

Deep Learning Model for Detecting and Counting Olive Trees in Satellite Imagery.

## Architecture
- Swin Transformer Tiny Encoder
- CNN-based U-Net Decoder
- Density Map Regression
- Count-Aware Fine-Tuning

## Dataset
OliveSatelital Dataset

## Framework
- Python
- PyTorch
- Google Colab
